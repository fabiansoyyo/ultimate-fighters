# 🥊 Ultimate Fighters

Un juego de lucha 2D desarrollado con HTML5 Canvas, CSS y JavaScript puro.

## 🎮 Demo

Próximamente disponible mediante GitHub Pages.

## 🚀 Características

- Combate para dos jugadores.
- Sistema de vida.
- Temporizador de combate.
- Ataques de puñetazo y patada.
- Detección de colisiones.
- Reinicio de partida.
- Escenario dibujado con Canvas.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas
- Git
- GitHub

## 🎯 Controles

### Jugador 1 (Rojo)

| Acción | Tecla |
|---------|---------|
| Mover izquierda | A |
| Mover derecha | D |
| Saltar | W |
| Puñetazo | F |
| Patada | G |

### Jugador 2 (Azul)

| Acción | Tecla |
|---------|---------|
| Mover izquierda | ← |
| Mover derecha | → |
| Saltar | ↑ |
| Puñetazo | K |
| Patada | L |
